### Commands
Search part of application name (e.g. andmenu)
Part of package name (e.g. com.cankurttekin.andmenu)
URL (e.g. https://example.com/)
Phone number (e.g. +1234567890)
Calculation formula (e.g. 2+3*5, 1inch in cm, 1m+1inch, 1m+1inch in cm)
One of commands below (e.g. help)

#### Available commands:
- help
- config
- date
- all_apps
- hidden_apps
- sys &lt;wifi|bluetooth|mobile_data|location|airplane_mode&gt;
- cal [&lt;month&gt; &lt;year&gt;]
- factor &lt;number&gt; ...
- bing &lt;query&gt;
- d &lt;query&gt;
- google &lt;query&gt;
- wikipedia &lt;query&gt;
- yahoo &lt;query&gt;
- ecosia &lt;query&gt;
- maps &lt;query&gt;
- yt &lt;query&gt;
- ytm &lt;query&gt;
- weather &lt;city&gt;
- m &lt;query&gt; (music)
- c &lt;query&gt; (contacts)

### Additional features to [Blue Line Console](https://github.com/nhirokinet/bluelineconsole)
- Fuzzy application search (optional)
- Sort results by usage frequency (optional)
- Additional search engines: ecosia, maps, youtube, youtube music
- Launch system settings windows like wifi, bluetooth, mobile data, location, airplane mode using sys <setting>
- Hide status bar when used as launcher (optional)
- Call or dial numbers
- Weather
- Search and play audio files
